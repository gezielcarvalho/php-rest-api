## Status

This is an instructional framework-free PHP API with MVC-style user CRUD, PDO/MySQL access, a custom router, Docker/Compose, phpMyAdmin, and migration assets. It is not a production service and is retained only as an archive/reference candidate.

The repository contains tracked local database/admin configuration. This documentation does not reproduce or change it; any future reuse requires separate credential remediation and security review.
