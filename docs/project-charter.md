# Project charter

## Purpose

Practice the fundamentals of a PHP REST API without a framework: routing, controller/model/view separation, PDO database access, JSON-style responses, and local Docker services.

## Verified current scope

- Custom router and MVC-style PHP structure.
- User CRUD endpoints backed by MySQL/PDO.
- SQL migration/sample-data asset.
- Docker Compose topology for Apache/PHP, MySQL, and phpMyAdmin.
- Makefile, health-check script, and local setup documentation.

## Outside current scope

- Authentication/authorization, password hardening, input/security review, tests, CI, observability, and production deployment.
- Managed secrets or secure non-local database administration.

## Portfolio decision

Classify as a learning/reference archive candidate. Its framework-free fundamentals are useful history, but current PHP/Laravel projects better represent portfolio-ready PHP work.
